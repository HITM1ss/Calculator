# 项目介绍
* 这是我的第一个程序，只是为了学习而创建的。
主要功能是一个加法计算器，用户可以在 UI 中输入两个整数，点击计算按钮后，会显示结果。
* 运行前请先安装python依赖，使用以下命令：
```
pip install -r requirements.txt
```
运行界面命令：
```
python ui/main.py
```
## 版本1.0.0 说明
1. 输入的必须是整数。
2. 整数可能会超出范围，显示错误的结果（受到c代码中int类型的范围限制）。
